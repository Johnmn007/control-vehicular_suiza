### 6.3 Marco Conceptual

Esta sección define operacionalmente los términos técnicos y computacionales fundamentales que sostienen la arquitectura del sistema SICISV. Todos los conceptos han sido formulados basándose en definiciones consensuadas por la literatura científica reciente de la ingeniería de software y la inteligencia artificial (IEEE, MDPI, 2021-2026).

**1. Aplicaciones Web Progresivas (PWA)**
Según las definiciones más recientes avaladas por conferencias internacionales de la IEEE, una Aplicación Web Progresiva o PWA (*Progressive Web App*) se define como un software de aplicación web híbrido que aprovecha las capacidades nativas de los navegadores modernos para proporcionar una experiencia de usuario robusta y rápida, idéntica a la de una aplicación móvil instalable. La literatura coincide en que su arquitectura depende de tres pilares fundamentales: ejecución estricta en un entorno seguro (HTTPS), un manifiesto web en formato JSON para la configuración de la interfaz a nivel del sistema operativo, y la implementación obligatoria de *Service Workers*. En el contexto de SICISV, este concepto se materializa como la interfaz principal que los agentes de seguridad instalan directamente en las tablets de las garitas perimetrales, omitiendo la necesidad y burocracia de las tiendas de aplicaciones tradicionales (como App Store o Google Play).

**2. Service Worker (Interceptor de Red)**
De acuerdo con las publicaciones técnicas de IEEE (2023-2024), un *Service Worker* se define operacionalmente como un script en segundo plano o *proxy* de red que opera de forma asíncrona y completamente desacoplada del hilo principal de ejecución del navegador web. Su función técnica principal es interceptar y administrar todas las peticiones de red que emite la aplicación. Al contar con estas capacidades de intercepción, este script decide de forma algorítmica si una solicitud de datos (como el registro de un ingreso vehicular) debe enviarse al servidor en la nube, o si debe redirigirse a una base de datos local para su almacenamiento temporal. Para el sistema SICISV, el *Service Worker* es el "cerebro" lógico de la conectividad, asegurando que los guardias no se enfrenten a pantallas de error o colapsos de sistema cuando la red inalámbrica de la zona industrial fluctúe o se caiga por completo.

**3. Inteligencia Artificial de Borde (Edge AI)**
Revistas científicas indexadas como *Sensors* (MDPI, 2024) definen el *Edge AI* como el paradigma informático de desplegar y ejecutar modelos de Inteligencia Artificial (tales como redes convolucionales o clasificadores de visión) directamente en los dispositivos periféricos, es decir, en el "borde" de la red. Esto contrasta con el modelo centralizado clásico que requiere enviar todos los datos masivos a la nube para su procesamiento. La literatura resalta que el *Edge AI* habilita inferencia en tiempo real, latencia ultrabaja y minimiza drásticamente los riesgos a la privacidad de la información biométrica. SICISV emplea este paradigma al ejecutar los algoritmos de detección y delimitación facial iniciales utilizando únicamente el poder de procesamiento del dispositivo del usuario (la tablet del vigilante), optimizando la transferencia de datos y acelerando la validación del conductor.

**4. Embedding Facial (Vector Descriptor Multidimensional)**
En el ámbito contemporáneo del procesamiento de visión por computadora (2023-2024), un *face embedding* o "incrustación facial" se define formalmente como un vector numérico continuo y de longitud fija (por ejemplo, una matriz de 512 dimensiones) que actúa como la representación matemática unívoca de un rostro humano. Las arquitecturas de redes neuronales profundas se encargan de mapear la topografía de los píxeles de una fotografía hacia este espacio hiper-dimensional, abstrayendo con eficacia el ruido ambiental como la iluminación defectuosa o el envejecimiento. Matemáticamente, este descriptor posee la propiedad crítica de que las distancias geométricas (euclidianas) entre dos vectores de una misma persona son sumamente cortas, mientras que los vectores de personas diferentes se repelen. Para SICISV, el *embedding* es el equivalente criptográfico de la huella dactilar de un conductor; el sistema jamás compara fotografías crudas (*raw*), sino que ejecuta búsquedas de similitud sobre estas matrices numéricas, asegurando una invulnerabilidad matemática.

**5. Arquitectura Offline-First (Primero Fuera de Línea)**
En la ingeniería contemporánea de sistemas distribuidos, el enfoque *Offline-First* es un paradigma estricto de diseño de software donde la aplicación se construye asumiendo como estado predeterminado la total ausencia de conexión a internet. Bajo este modelo computacional, las operaciones críticas de lectura y escritura siempre interactúan primero con el almacenamiento local persistente del dispositivo cliente (como el estándar *IndexedDB*). Únicamente en un proceso secundario o en segundo plano, un motor algorítmico de sincronización se encarga de trasladar esos datos locales hacia la base de datos maestra en el servidor central. En el proyecto SICISV, este concepto es la garantía absoluta de la continuidad logística: el agente puede registrar ininterrumpidamente las matrículas y los rostros de cientos de transportistas sin red de datos, mientras el sistema orquesta la sincronización silenciosa y automática en cuanto la infraestructura de telecomunicaciones se estabilice.
